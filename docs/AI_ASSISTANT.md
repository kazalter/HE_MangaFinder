# AI 助手

MangaFinder 的 AI 助手用于用自然语言查询已采集的作者动态、作品发现、发布信号和本地作品资料。它使用系统设置中的 DeepSeek provider、API 地址与模型（当前配置为 DeepSeek Flash）。

## 数据与回答

- 助手只通过服务端的固定 SQLAlchemy 查询读取作者、作品、发现事件、社交动态、发布信号和最近扫描记录；模型不能生成 SQL，也没有任意数据库工具。
- 提问时，服务端只把相关的有限记录发给 DeepSeek 生成回答。帖子正文和作品简介会截断；对话不会写入数据库。
- 回答以本地最近一次采集结果为准，显示帖子时间、扫描时间或作品首次发现时间，并在可用时附上来源链接。它不会代替实时网络搜索。
- 聊天接口需要管理员登录和 CSRF 校验，并按管理员账号限制请求频率。API Key 始终只在服务端使用。

## 变更确认

模型不能直接写数据库。用户明确要求修改时，助手可以生成以下变更预览：

- 作品元数据：标题、简介、年份、状态、语言、标签、封面版本或首选版本。
- 待发布作品：标题、状态、发布日期、活动代码或摊位。

预览展示字段的当前值与拟修改值，有效期为 10 分钟。只有管理员点击“确认并保存”后，服务端才会重新检查当前值并调用已有校验逻辑写入。记录在预览期间发生变化时，确认会被拒绝，用户需要重新生成预览。合并、删除、拆分和作者身份修改不开放给助手。

待确认预览保存在 API 进程内存中，服务重启后会失效；聊天记录只保留在当前浏览器页面内。
